# tebak-alat-musik
Game Tebak Alat Musik Tradisional Daerah adalah permainan edukasi interaktif yang bertujuan  mengenalkan berbagai alat musik tradisional dari seluruh daerah di Indonesia.Pemain harus menebak nama alat berdasarkan petunjuk yang di berikan.Game ini dirancang untuk menambah wawasan, melestarikan budaya indonesia.
